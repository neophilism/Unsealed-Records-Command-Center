# URC-07 TooLost statement boundary

The statement projection validates typed label/statement/line/release/track IDs, period, currency, signed royalty amounts, source revision and document SHA-256. Explicit nested label, statement and currency metadata must agree with the statement. It reconciles the exact BigInt sum of royalty, reversal and adjustment lines to the declared total. Source projection copies only the five declared provenance fields; unexpected debug/credential fields are dropped. Synthetic records retain their synthetic marker. Line drill-down cannot select an absent line.

The same-origin client requests `/api/labels/{labelId}/reports/toolost` through the authenticated BFF without a provider key. It validates every returned statement, rejects duplicate label/statement/source-kind identities, rollback and conflicting equal revisions, and retains bounded SHA-256 proofs instead of raw document metadata in its revision map (at most 2000 keys). It defaults to observed (`live` kind) statements; demo statements require explicit `{sourceKind:'synthetic'}` and cannot supersede observed revisions. Reads use no-store, strict JSON/UTF-8, a 2 MB byte cap, cancellation and a bounded deadline (default 10 seconds, maximum 30). Provider diagnostics are not exposed.

`mountTooLost(root, options)` in `src/toolost-view.mjs` returns `load(labelId, statementId, selection)` and `dispose()`. It mounts exact currency totals, native accessible line detail controls, signed royalty/reversal/adjustment amounts and source observation metadata. Supply verified `currencyDigits`; no currency scale is inferred. Unknown scales display unavailable amounts. The mount clears prior statement data on selection changes and disposal. Browser/accessibility acceptance remains unverified because an installed Chromium executable was unavailable in this activation.

`compareTooLostArtifact(bytes, statement, options)` hashes 1–16 MB of supplied bytes and compares them with the statement's claimed SHA-256, bound to its label/statement metadata. The UI can compare a locally selected document without uploading it. A byte match establishes only equality to the claimed digest: it does not authenticate the provider, verify payout, establish rights or prove that a fixture came from TooLost. Synthetic comparisons remain labeled demo. Actual provider artifact retrieval/ingestion belongs in the Engine, not this frontend.

No TooLost provider API, document ingestion, payout reconciliation, or authenticated Music Operations Engine statement contract has been verified. The BFF must enforce user grants and source authentication, and the document hash must be compared to the actual provider artifact before this view is treated as live evidence. The legacy `projectTooLostStatement` remains for earlier draft consumers.
