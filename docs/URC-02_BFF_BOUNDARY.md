# URC-02 backend-for-frontend trust boundary

A pure, fail-closed authorization predicate is a partial foundation for a future server-only Music Operations Engine proxy. No deployed authentication, session issuer, secrets, per-label middleware or upstream API contract has been verified. `serverVerified` and token claims must come from independently verified server identity and authorization, never from a browser parameter. Deny cross-label access and expired tokens. Keep provider API keys in server secrets, never in a frontend bundle. All upstream domain contracts must pass before enabling real requests. Pending: signed tokens, rotation, provider contract pin, retries, out-of-order source handling, bigint-safe serialization, request audits, and full negative/integration tests.
